Correlation

A factor covariance model — V = BΩBᵀ + Ψ — built end to end and shown working, or not. Each instrument's daily returns are regressed on {{ factors|length }} tradable factor proxies (B, the exposures); the factors' own covariance is estimated in two clocks — fast for volatility, slow for correlation (Ω); what the factors cannot explain becomes diagonal idiosyncratic variance (Ψ). Every estimator is a causal EWMA, so the model line on any date is what the model would have said on that date — which is what makes comparing it to the realized rolling correlation a test rather than a fit. This page is a verification tool: nothing here trades.
